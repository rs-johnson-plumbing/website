# Photos

Real photos go here. Naming convention:

- `crew-<firstname>.jpg` — one per crew member (e.g. `crew-ryan.jpg`)
- `crew-group.jpg` — whole crew in front of the trucks
- `project-<city>-<nn>.jpg` — job photos (e.g. `project-chesterfield-01.jpg`)
- `site-<description>.jpg` — everything else (e.g. `site-truck-three-quarter.jpg`)

Alt text and captions come from the content files in `/content`, not from
the file name. Until a file exists, the site shows a labeled placeholder.
